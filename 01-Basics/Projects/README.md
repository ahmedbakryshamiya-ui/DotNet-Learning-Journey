# C# Basics — Practical Projects

Three small console projects that apply the fundamentals covered in this section.

| Project | Main concepts | Run |
|---|---|---|
| [Currency Conversion Software](CurrencyConverter/README.md) | Variables, constants, input, switch, arithmetic | `dotnet run --project CurrencyConverter/CurrencyConverter.csproj` |
| [Inventory Management System](InventoryManagementSystem/README.md) | Arrays, loops, methods, conditions, user input | `dotnet run --project InventoryManagementSystem/InventoryManagementSystem.csproj` |
| [Quiz Game](QuizGame/README.md) | Arrays, loops, methods, conditions, exceptions | `dotnet run --project QuizGame/QuizGame.csproj` |

Each project contains its source, project/solution files, a short README, and an editable Draw.io process diagram with an SVG preview.
