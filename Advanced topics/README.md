# Advanced topics

## Streams and Files

This section contains the Streams and Files topics moved from the OOP learning path. The original examples, explanations, comments, and Microsoft Learn references are preserved.

### Run

Open [Advanced-CSharp.slnx](Advanced-CSharp.slnx) in Visual Studio, or run this command from the repository root:

```bash
dotnet run --project "Advanced topics/Advanced-CSharp.csproj"
```

Choose one of the four lessons from the console menu.

### Topics

| Topic | What it covers |
|---|---|
| [Stream I/O](Examples/07-Streams-And-Files/01-StreamIO.cs) | FileStream byte operations, StreamWriter, StreamReader, and File helpers. |
| [Finalizers and Destructors](Examples/07-Streams-And-Files/04-Finalizers.cs) | Garbage-collector finalization and why it is not predictable cleanup. |
| [IDisposable and Dispose](Examples/07-Streams-And-Files/03-IDisposableAndDispose.cs) | Manual Dispose, try/finally, and using patterns. |
| [DeflateStream](Examples/07-Streams-And-Files/02-DeflateStream.cs) | Compressing and decompressing stream data. |
